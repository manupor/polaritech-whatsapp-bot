# Welcome Image

Place the welcome image here as `polaritech-cotizacion.jpg` (or any supported format).

## Usage

The bot sends this image to new conversations. Configure one of:

- `WHATSAPP_WELCOME_IMAGE_URL` — public URL of the image
- `WHATSAPP_WELCOME_IMAGE_ID` — pre-uploaded Meta media ID

If neither is set, the bot sends only the welcome text.

## Supported formats

WhatsApp supports: JPEG, PNG (max 5 MB).
